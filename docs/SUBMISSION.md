## Перед отправкой организаторам

1. Выдать **публичный HTTPS URL, API URL и X-API-Key** отдельно. Проверить их с другой сети. SSH-туннель команды не подходит как адрес для жюри.
2. Основной адрес — https://forte.makquiz.site:14901, Swagger — `/docs`. Прямой HTTPS; поддомен в режиме DNS only. Не останавливать оплаченный сервер. Сертификат действует до 16.01.2027; продление ручное.
3. Проверки API и браузера приведены в [обновлении аудита](READINESS_FIXES_20261018.md); не смешивать их с оценкой качества на новом ракурсе.
4. Убедиться, что очередь пуста, `worker: ready`, GPU не занят обучением; не останавливать оплаченный сервер во время проверки жюри.
5. Указать командное авторство backend и лицензии используемых компонентов. Сохранить MIT attribution.
6. В презентации указывать фактические метрики и ограничения, не заявлять независимые 17/21 или 21/21.
7. Зафиксировать Git commit сдачи. Эксперименты и обучение проводить отдельно, не заменяя работающий checkpoint без повторной проверки.

Исходный датасет, отчёты с кадрами, ключи и личные серверные настройки не публикуются в репозитории.
