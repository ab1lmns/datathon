## Описания и API

`service/event_wording.py` изменяет только распознанные стандартные шаблоны движка, помечая их как сигнал системы. Произвольные тексты не переписываются. Убраны необоснованные утверждения о содержимом сумки, роли инкассатора, отсутствии проверки, полномочиях человека и наличных рядом с чашкой.

`rule.relation` различает CONDITIONAL_BASIS, RELATED_ONLY, NO_DIRECT_BASIS. Для косвенных оснований интерфейс явно показывает «Связанное требование, не прямое основание». При отсутствии подходящего основания ссылка не выдумывается.

Коды/названия категорий API остаются совместимыми; это названия детекторных категорий, а не установленные юридические факты. Вердикты, количество событий, таймкоды и кадры не изменяются. Исходные результаты GPU-сервиса и сохранённые JSON остаются прежними; исправление выполняется при выдаче через публичный gateway. Нормативные ошибки не скрываются удалением событий.

`backend/regulatory/applicability_sources.json` содержит выбранные точные абзацы. Тест сверяет каждую цитату с соответствующим HTML-якорем сохранённого официального текста. Исходный поставленный нормативный пакет не переписан.
