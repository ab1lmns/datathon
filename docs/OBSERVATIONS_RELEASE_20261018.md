Для второго человека нормативная связь `RELATED_ONLY`.

## Устройство

- `forte/patch_features.py`: пространственные признаки замороженного DINOv2, совпадающая с обучением обработка изображения.
- `forte/folder_observations.py`: локализация папки, последовательные наблюдения, три исходных кадра.
- `forte/reflection.py`: сравнение фигур замороженной Qwen, восстановление только подтверждённого участка трека.
- `forte/observations.py`: подключение обоих компонентов после формирования исходных событий; исходные события не переписываются.
- `forte/pipeline.py`: вызов дополнений внутри одного Analyzer. Существующие Qwen и совместимый DINOv2 используются повторно. Нет зависимости от другого API, исследовательских папок или имени видео.
- `models/folder_patch_heads.joblib`: сохранённый checkpoint, проверяемый по SHA-256 при старте; используются только веса `folder`.

`FORTE_OBSERVATIONS=1` — по умолчанию. `0` отключает оба дополнения. При включённом режиме отсутствие весов или Qwen мешает старту worker; ошибка анализа возвращает `failed`, не маскируется под отсутствие нарушения. Общий дедлайн worker/очереди сохраняется; дополнения получают остаток внутреннего бюджета 270 с.
