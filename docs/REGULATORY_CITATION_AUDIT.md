# Аудит ссылок и нормативных формулировок — 18.10.2026

## Итог

Исправлена выдача нормативных оснований в публичном web/API gateway.
Это проверка согласованности с поставленным нормативным пакетом и ограничений
применимости, **не завершённая независимая сверка действующего законодательства**.

Официальные страницы актов №231 и №14 через web-инструмент и прямой HTTPS
вернули JavaScript-оболочку (1573 байта), без текста. В официальном JS найден
публичный маршрут API документов; поиск вернул 401, получение по прежнему ID — 404.
Старый официальный домен через web-инструмент недоступен. Обход авторизации не
выполнялся. Дата/статус VERIFIED в пакете — заявление автора, не результат этой сверки.
Чтобы завершить сверку редакций и абзацев, нужен доступный официальный текст или
экспорт документа из «Әділет». До этого не заявлять «все нормы точно проверены».

## Исправления

- Убирается только точный старый нормативный суффикс из description. Наблюдение,
  тип, время, кадры и verdict сохраняются. Неизвестные произвольные тексты не обрезаются.
- Взамен указано, что применимость не установлена автоматически; точные пункты,
  официальные ссылки и условия находятся в «Правило».
- Для открытого сейфа не выдаётся п.80 как универсальное доказательство нарушения;
  для двери/постороннего поясняется косвенный характер норм об устройстве помещения.
- Для стакана не утверждается автоматическое нарушение п.12.
- Для рабочей станции исключена клиентская инструкция онлайн-банкинга как обязанность
  кассира. Указано, что требование автоблокировки через 30 минут нельзя доказать коротким
  роликом. Прежние официальные ссылки показаны как неперепроверенная справка.
- Каждый пункт имеет официальный URL. UNKNOWN остаётся UNKNOWN.
- Автоматический юридический выбор экспериментальной Qwen не включается.

## Область обновления

Gateway обогащает уже сохранённые и новые результаты при GET /api/v1/jobs/{id}.
Исходные записи GPU API/SQLite не переписываются. Прямой внутренний GPU API сохраняет
прежний текст; для сдачи использовать публичный gateway. Данные, уже загруженные в
память браузера, могут потребовать повторного получения результата.
Модели и GPU worker не меняются и не перезапускаются.

13 backend-тестов пройдены, включая отсутствие изменения visual verdict, времени и
кадров, замену только известных нормативных суффиксов и наличие официальных ссылок.

Проверка после развёртывания: 8 разных типов событий на реальных сохранённых задачах.
У 8 описаний заменён прежний нормативный суффикс. Типы, verdict, таймкоды и все
кадры совпадают с внутренним GPU API. Все источники ведут на adilet.zan.kz.
Gateway и GPU health: ok / ready, очередь 0, worker не занят.
