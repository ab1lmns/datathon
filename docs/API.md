# API

Базовый адрес — тот же HTTPS-сайт, что и интерфейс. `X-API-Key` обязателен для загрузки и чтения результата. Не передавайте ключ в URL.

```bash
# BASE_URL и API_KEY задаются локально, не сохраняются в Git.
curl --fail-with-body -X POST "$BASE_URL/api/v1/analyze" \
  -H "X-API-Key: $API_KEY" -F 'file=@example.mov'

curl --fail-with-body "$BASE_URL/api/v1/jobs/JOB_ID" \
  -H "X-API-Key: $API_KEY"
```

Первый ответ: `{"job_id":"..."}`. Опрашивайте результат примерно раз в две секунды.

```json
{
  "job_id": "...",
  "status": "done",
  "verdict": "violation",
  "violations": [{
    "type": "Название типа",
    "timecode_sec": 12.5,
    "description": "Наблюдаемое действие и нормативное основание",
    "evidence_frames": [{"timestamp_sec": 12.5, "image_base64": "JPEG_BASE64"}],
    "rule": {"document": "Название документа", "section": "Пункт", "url": "https://adilet.zan.kz/..."}
  }]
}
```

`rule` — дополнительное поле gateway для карточки нормативного источника. Оно берётся из поставленного нормативного модуля и явно помечается `assessment: NEEDS_REVIEW`: backend пока не подтверждает все условия применимости. События, исходное описание, таймкод и JPEG не переписываются. Исходное описание может содержать прежнюю нормативную формулировку модели; рядом интерфейс показывает ограничения применимости, а окно «Правило» — актуальное сопоставление. Основной JSON-контракт ТЗ сохранён.

Без нарушения: `verdict: no_violation`, `violations: []`. При обработке: `status: processing`. При ошибке: `status: failed`, `error` с причиной; это не отрицательный результат.

HTTP 401: ключ отсутствует или неверен. 400: пустой файл/не MOV. 413: превышен лимит. 404: задания нет. 503: GPU API недоступен. Файл с MOV-расширением, но испорченным содержимым может быть принят, а затем завершиться `failed`.

`GET /api/v1/health`: `status: ok`, `worker: ready` означает готовность; `loading` — загрузка моделей. Health не проверяет API-ключ. Поле `queue` показывает ожидающие задания, `busy` — работу текущего worker.

На уровне UI ожидание ограничено 300 с. На уровне worker таймаут задачи 300 с; очередь может добавить время, поэтому тестировать сдачу следует без конкурирующих загрузок/обучения. Отмена ожидания в браузере не отменяет уже принятую серверную задачу.

Исходные видео удаляются после обработки. Кадры и результаты остаются на сервере и доступны по ID с ключом команды. История UI хранится в памяти текущей вкладки; после перезагрузки список сбрасывается. API-результат по сохранённому `job_id` остаётся доступен.

## Нормативный модуль (18.10.2026)

В `backend/regulatory` сохранены исходный JSON, схема и SHA-256 архива. 72 записи: 66 VERIFIED по заявлению автора, 6 UNVERIFIED. VERIFIED относится к нормативной основе, а не к доказанности события.

`rule.sources` содержит официальные ссылки и точные пункты; `rule.rule_ids` — записи модуля; `rule.reason` — ограничение сопоставления; `rule.unknown_conditions` — необходимые условия, пока UNKNOWN; `rule.checked_at` — дата проверки, заявленная автором пакета. Отсутствие входных условий никогда не преобразуется в TRUE.

Прямые тематические кандидаты: A → CASH_006/008 (только при доказанных условиях денег/приёма), C → CASH_006, D → CASH_018 (ручная проверка), F → CASH_035, G → CASH_001, I → CASH_059 (ручная проверка), J → CASH_005. Эти ссылки не включают отключённые детекторы D/I/J.

Только связанные нормы для ручного сопоставления: B → CASH_007, E → CASH_047, H → CASH_047/048. Открытая дверца не доказывает невозможность запирания, наличие человека не устанавливает допуск, открытая дверь не доказывает дефект устройства помещения.

Для L (экран) в присланном пакете нет подходящей записи: сохранена прежняя официальная ссылка с явным сообщением, что она вне пакета и требует ручной проверки. Неподтверждённый CASH_033 не используется как универсальное основание для «денег без присмотра»; норма обменного пункта CASH_053 не подставляется для обычной кассы.

Официальные страницы Әділет открыты при интеграции, но веб-инструмент получил JavaScript-оболочку без текста. Независимая повторная сверка актуальной редакции не заявляется. Использованы исходные тексты и метаданные поставленного пакета.

Юридический фильтр не скрывает визуальные события: количество, вердикт, тип, описание и PTS сохранены; добавлены ссылки и сведения об ограничениях. Улучшение recall/FP не заявляется.

### Уточнение нормативных формулировок (18.10.2026)

Публичный gateway заменяет точный устаревший нормативный суффикс `description`
на указание проверить применимость в `rule`. Визуальная часть, type, timecode_sec,
evidence_frames и verdict сохраняются. Это действует при чтении новых и старых задач;
внутренний GPU API и сохранённые исходные записи не изменяются.
Наличие официальной ссылки не означает подтверждённую применимость.
`rule.source_verification` отличает справочник автора пакета от прежних ссылок;
полная независимая сверка официальных редакций пока не завершена.
Подробности: [аудит](REGULATORY_CITATION_AUDIT.md).
