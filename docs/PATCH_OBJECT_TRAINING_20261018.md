# Обучение предметного компонента — 18.10.2026

## Результат и статус

Свежий прогон действующего API на всех 40 уникальных видео подтвердил **15 TP, 6 FN, 0 FP, 19 TN**. Загрузки имели нейтральное имя `video.mov`; каждый запрос создавал новую задачу и заново извлекал признаки. Максимальное время одного локального запроса — 16,61 с. Это знакомый development-набор, не независимая оценка.

Отдельно обучен новый предметный компонент. Полный скан 40 исходных видео, 2612 кадров с частотой около 2 кадров/с, нашёл дополнительную последовательность в **Х-24**: папка на столе остаётся после ухода. В Х-25, где папку убрали, дополнительного события нет. На других 38 видео таких кандидатов нет.

При учёте этого наблюдения как A «оставленные ценности», согласно ранее подтверждённому пользователем статусу папки Х-24, объединённый экспериментальный результат составляет **16/21 и 0/19**. После отдельного скана этот результат также подтверждён новым прогоном всех 40 видео через **изолированный кандидатный API**; публичный API не обновлён. Содержимое папки и её нормативный статус визуальная модель не устанавливает. Бинарный подсчёт также не исправляет известные ошибки типа и времени старых событий.

**Production не менялся.** Проверены неизменные SHA-256 28 файлов рабочего пакета `forte` и классификаторов. API продолжал работать, его не останавливали. Проверка полностью без сети остаётся отложенной задачей.

## Что обучалось

- Замороженный DINOv2-base, ревизия `f9e44c814b77203eaa57a6bdbbd535f21ede1415`.
- Три отдельные логистические головы: папка, сумка, банкноты против фона. Новые веса Qwen/RT-DETR не обучались.
- Полный кадр с сохранением пропорций, длинная сторона 784 px, размер кратен 14. Предсказание по пространственным признакам патчей, без координат предмета на входе.
- Рамки используются только как учебные метки и для последующего подсчёта локализации. На inference нет имени ролика, пользовательской заметки, GT-таймкода или GT-вырезки.
- 24 ранее размеченных исходных кадра. Train: Х-13/24/25/26, evaluation: Х-15/23/43/44. Группы сцен, SHA исходников и кадров не пересекаются. Положительная папка есть только в одной группе Х-24/25, поэтому перенос на другую папку/камеру не проверен.
- Метки авторства ассистента из сохранённого `object_grounding_v1`; прежнее уточнение пользователя сохранено как контекст, а не новая человеческая проверка всех рамок. UNKNOWN исключён из обучения соответствующей головы.

## Исправление первой попытки

Первая версия использовала по 128 случайных отрицательных патчей на кадр. Она находила папку, но давала ложные предметные ответы даже на учебных кадрах. Поэтому добавлены два прохода сбора трудных отрицательных патчей **только из train**. Evaluation в обучение не добавлялся; порог обнаружения 0,90 не менялся. Первый результат и исходный скрипт сохранены, не затёрты.

После этого на учебных кадрах локализованы папки 4/4, сумки 2/2, банкноты 4/4; ложных предметных YES на размеченных NO нет. На evaluation:

| Голова | Локализованы положительные | Ложные YES на NO |
|---|---:|---:|
| Папка | положительных нет | 0/12 |
| Сумка | 1/3 | 0/9 |
| Банкноты | 0/3 | 0/6 |

Сумка и банкноты **не прошли проверку переноса**; заменять ими работающие классификаторы нельзя. Для дальнейшего полного скана использовалась только голова папки. Повторное использование evaluation после диагностики отмечено: это development-проверка, не финальный независимый тест.

## Полный скан и доказательства

Кандидат формируется при двух последовательных наблюдениях одного локализованного предмета на автоматически найденном столе, когда текущий трекинг показывает пустое помещение. Интервал между наблюдениями 0,45–0,8 с, IoU рамок не меньше 0,3. Полные видео просканированы равномерно; время события не взято из разметки.

В Х-24 первое такое подтверждение: кадры **405 и 420**, PTS **13,5 и 14,0 с**. Папка остаётся и на кадре 435, **14,5 с**. Эти PTS отдельно сверены с `ffprobe` по исходнику. Кадр 13,0 с даёт контекст ухода. На контактном листе визуально проверены локализация папки и контроль Х-25.

Есть отдельные ложные/неоднозначные предметные находки на Х-4, Х-8, Х-14 и Х-32, однако они не образовали событие «оставлено после ухода». Поэтому **0/19 относится к итоговым кандидатам событий**, а не ко всем рамкам. Это существенный оставшийся риск для новых записей.
