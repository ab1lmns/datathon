# Выбор объектов на кадре

Просмотр кадра поддерживает наведение на рамку, выбор мышью или клавиатурой и карточку объекта слева. Список объектов позволяет выбрать также маленькие и перекрытые рамки. На телефоне карточка находится под изображением.

Каждый `evidence_frames[]` может дополнительно содержать `objects[]`:

```json
{
  "id": "scene:safe",
  "kind": "safe",
  "name": "Сейф",
  "state": "закрыт",
  "bbox": [0.66, 0.43, 0.89, 0.63],
  "color": "#00c8c8",
  "history": [
    {"timestamp_sec": 0, "state": "закрыт"},
    {"timestamp_sec": 23, "state": "открыт"}
  ]
}
```

Координаты `bbox` — нормализованные `[x1, y1, x2, y2]` относительно всего JPEG, включая изображённую сцену. Рамки формируются там же, где рисуются подписи JPEG: отдельного повторного распознавания нет. Пример выше иллюстрирует формат и не является результатом анализа.

Сейф, дверь, экран и стол имеют устойчивые ID в пределах одного видео. Люди используют ID трекера; трек не устанавливает личность. Для мелких предметов и папок устойчивых треков нет, поэтому ID действуют только в конкретном кадре. Нельзя объединять все сумки или всех посетителей в одного участника.

История сейфа содержит изменения состояний классификатора; пробелы в покрытии отмечаются отдельно. Дверь и экран содержат только реально выполненные запросы VLM. Остальные наблюдения собираются из доступных кадров данного отчёта. События в карточке относятся к кадрам, на которых присутствует объект: это не автоматическое установление участника нарушения.

## Обновление сервера

Одного обновления frontend недостаточно: ранее развёрнутый GPU-backend возвращает рамки только внутри JPEG. На сервер нужно доставить обновлённый `backend/forte/pipeline.py` вместе с новым `backend/forte/evidence_objects.py`, затем перезапустить сервис с worker штатным способом, когда очередь свободна. Новые веса и дополнительные модели не нужны.

После обновления заново проанализировать видео и проверить наличие `objects` у кадров в ответе `GET /api/v1/jobs/{id}`. Старые сохранённые результаты не получают координаты автоматически; интерфейс продолжает показывать их и объясняет отсутствие выбора объектов.

## Проверка объединённой версии

Изменения объединены с `forte-observations-v1`: координаты передаются также для папок и подтверждённых дополнительных людей. Содержимое папки и полномочия человека из рамки не следуют.

Проверки и результаты выкладки записаны в [отчёте интеграции](UI_MERGE_20261018.md). В текущей сессии встроенный браузер недоступен; ручной визуальный прогон нового интерфейса после объединения не подтверждён. Проверены сборка, автоматические тесты и фактические API-ответы.
