# Подключение frontend и backend

Актуальная инструкция: [README](../../README.md), [API](../../docs/API.md).

Фронтенд обращается к `/api/v1/analyze`, `/api/v1/jobs/{id}`, `/api/v1/health` на текущем origin. Gateway отдаёт React и проксирует API, сохраняя X-API-Key. Vite для разработки проксирует API на localhost:8080. Ключ хранится только в памяти вкладки, не включается в сборку.

Дизайн и CSS сохранены. Состояние модели берётся из реального worker. При ошибке нет подстановки демо-результата. Демо отключено в сдаваемой сборке, датасет не публикуется.

Загрузка: непустой MOV до 200 MiB, multipart `file`; ожидание до 300 с. Результат: несколько событий, у каждого 1–3 JPEG, таймкод, описание и `rule` со ссылкой на нормативный источник. Прогресс отображается только если сервер его сообщает.
