## Дополнительная голова папки

`models/folder_patch_heads.joblib` — SHA-256 `24ee6b8d06058ec202d3471df78e6400f991f81e2fdf588b3ce96b9e028af780`. Из пакета используется только голова `folder`; головы денег и сумки не прошли оценку и не подключены. Пространственные признаки DINOv2 строятся по полному кадру, длинная сторона 784 px, порог 0,90. При совпадении ревизии переиспользуется DINOv2 классификатора сейфа. Qwen для проверки отражений также переиспользуется; второго экземпляра Qwen и обращений к другому API нет.

`FORTE_OBSERVATIONS=1` включает оба дополнения (по умолчанию). Значение `0` возвращает базовый анализ. При включённом дополнении отсутствие/повреждение checkpoint или отсутствие Qwen останавливает запуск worker; ошибка анализа новой ветки завершает задачу ошибкой, а не результатом «нарушений нет».

Веса головы обучались на знакомой группе X-24/25; независимой положительной группы папки для оценки нет. Qwen в этом обновлении не дообучалась. Содержимое папки и полномочия второго человека не устанавливаются моделью; обоснования сохраняют эти ограничения.
