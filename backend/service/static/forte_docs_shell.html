Документация API

Загрузите запись кассовой операции и получите найденные события, таймкоды, кадры-доказательства и нормативные источники.

Вставьте только значение ключа — без префиксов Bearer и X-API-Key. Ключ хранится только в памяти этой вкладки.

01 / ЗАГРУЗКА

Отправьте видео

POST analyze → Try it out. Выберите MOV и нажмите Execute.

02 / ОБРАБОТКА

Сохраните job_id

Идентификатор из ответа связывает загрузку с результатом.

03 / РЕЗУЛЬТАТ

Получите события

GET jobs: повторяйте запрос до статуса done или failed.
