# Forte · Видеоконтроль

React + TypeScript интерфейс и базовый FastAPI-бэкенд.
API принимает MOV, хранит статусы и запускает обработку в отдельном процессе.
AI-модель пока не подключена: новые видео завершаются понятной ошибкой без фиктивного вердикта.

Запуск API и документация: [backend/README.md](backend/README.md).

```bash
cd backend
source .venv/bin/activate
python -m app
```

В отдельном терминале, из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Сборка: `npm run build`. Контрактные тесты: `npm test` (Node 24 рекомендуется).

## Для команды backend / AI

Базовый сервер находится в `backend/`. Точка подключения локальной модели —
`backend/app/analyzer.py`. Swagger UI после запуска: http://127.0.0.1:8000/docs.

Полная инструкция подключения: [frontend/docs/BACKEND_HANDOFF.md](frontend/docs/BACKEND_HANDOFF.md).

- `frontend/src/api/types.ts` — контракт API и типы UI.
- `frontend/src/api/client.ts` — загрузка MOV, X-API-Key, опрос, проверка ответа.
- `frontend/src/hooks/useReviews.ts` — состояния, таймаут 5 минут, отмена, повтор, локальные примеры.
- `frontend/src/components/ConnectionSettings.tsx` — выбор режима, адрес сервера и ключ в памяти.
- `frontend/src/App.tsx` — рабочее пространство и навигация; `components/ReviewDetail.tsx` — события, кадры и плеер.

По умолчанию выбран режим API. Три примера исходной разметки доступны при выборе демо на странице «Подключение». Подключение настраивается на странице «Подключение». Для произвольных видео демо не выдумывает вердикт. Серверные кадры-доказательства отображаются отдельно от предпросмотра исходного видео.

Локальные демо-видео исключены из Git; перед публичной сборкой удалите их из `frontend/public/demo/`, иначе Vite скопирует их в dist. Датасет не публиковать.

## Интерфейс

Мобильная версия с нижней навигацией, отдельным поиском и диалогами, открывающимися снизу. Карточки быстрого доступа сохраняют форму папок. Папки открываются при нажатии, разделы появляются последовательно. При загрузке страницы 3D-логотип Forte поворачивается в центре и перемещается в шапку; заставку можно пропустить, её максимальная длительность — 4,4 секунды. Учитывается настройка уменьшения движения. Golos Text с кириллицей подключён локально через Fontsource; иконки — Lucide. При отсутствии WebGL отображается обычный логотип.

Страницы: «Обзор», «Видеоотчёты» (папки и отдельный отчёт, экспорт JSON), «Источники», «Подключение» (состояние сервера и модели). FAQ расположен внизу бокового меню. Локальный Vite проксирует `/api` и `/health` на `127.0.0.1:8000`; пустой адрес API использует этот прокси. В production нужен аналогичный reverse proxy или явный адрес API. Ключ вводится пользователем и остаётся в памяти вкладки. Ответ `/health` подтверждает доступность сервера, но не валидность ключа или выполнение анализа.
