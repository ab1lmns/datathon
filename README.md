# Forte · Видеоконтроль

Компактный React + TypeScript интерфейс. Бэкенд не реализован.

```bash
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Сборка: `npm run build`. Контрактные тесты: `npm test` (Node 24 рекомендуется).

## Для команды backend / AI

Полная инструкция подключения: [frontend/docs/BACKEND_HANDOFF.md](frontend/docs/BACKEND_HANDOFF.md).

- `frontend/src/api/types.ts` — контракт API и типы UI.
- `frontend/src/api/client.ts` — загрузка MOV, X-API-Key, опрос, проверка ответа.
- `frontend/src/hooks/useReviews.ts` — состояния, таймаут 5 минут, отмена, повтор, локальные примеры.
- `frontend/src/components/ConnectionSettings.tsx` — выбор режима, адрес сервера и ключ в памяти.
- `frontend/src/App.tsx` — рабочее пространство и навигация; `components/ReviewDetail.tsx` — события, кадры и плеер.

По умолчанию открыт демо-режим с тремя примерами из исходной разметки. Настоящий анализ включается через «Как это работает» → «Настройки подключения». Для произвольных видео демо не выдумывает вердикт. Серверные кадры-доказательства отображаются отдельно от предпросмотра исходного видео.

Локальные демо-видео исключены из Git; перед публичной сборкой удалите их из `frontend/public/demo/`, иначе Vite скопирует их в dist. Датасет не публиковать.

## Интерфейс

Мобильная версия с нижней навигацией, отдельным поиском и диалогами, открывающимися снизу. Карточки быстрого доступа сохраняют форму папок. Папки открываются при нажатии, разделы появляются последовательно. При загрузке страницы 3D-логотип Forte поворачивается в центре и перемещается в шапку; заставку можно пропустить, её максимальная длительность — 3,4 секунды. Учитывается настройка уменьшения движения. Manrope из Google Fonts хранится локально (`public/fonts`), без запросов к Google при запуске. При отсутствии WebGL отображается обычный логотип.
