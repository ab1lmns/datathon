# Forte — видеоаналитика кассовых операций

**MOV → локальный анализ → события с таймкодами, кадрами и нормативными источниками.**

Сборка для Datathon 26: существующий интерфейс команды и исходники действующего GPU-сервиса. В публикуемый комплект не входят обучающие видео, секреты и экспериментальные адаптеры. В локальной рабочей папке могут оставаться исключённые из Git данные `open/` и исходное ТЗ.

## Что находится в проекте

```text
frontend/                 React + TypeScript + Vite, существующий дизайн
backend/
  service/app.py          асинхронный FastAPI и очередь GPU-задач
  service/gateway.py      единый адрес для интерфейса и API
  forte/                 действующий движок анализа (пакет forte)
  models/                два небольших классификатора
  docs/                  реестры нормативных источников
  deploy/                снимок зависимостей и контрольные суммы сервера
  scripts/               загрузка фиксированных весов и проверка исходников
  tests/                 контракт gateway, без GPU
docs/                     API, запуск, проверка сдачи, происхождение кода
```

## Открыть уже работающий сервис

Основной адрес: **https://forte.makquiz.site:14901**. [Swagger / интерактивный API](https://forte.makquiz.site:14901/docs).

Введите выданный ключ в разделе подключения; API-адрес оставьте пустым. В Swagger используйте «Подключить ключ API». Ключ передаётся отдельно, не в URL.

HTTPS завершается на сервере команды; Cloudflare используется только для DNS этого поддомена. Порт `14901` обязателен. Сервис зависит от работающей аренды и сохранения IP/проброса порта, бесперебойность не гарантируется. Сертификат действует до 16.01.2027, продление пока ручное: [инструкция](backend/deploy/direct-https/README.md).

Исторические туннели не являются основным адресом сдачи. Результаты проверки нового транспорта: `docs/evaluations/direct-https-api-20261018.json`.

### Приватный доступ с Mac через SSH

```bash
ssh -N -i ~/.ssh/fortebank_vast -p 14814 \
  -L 17860:127.0.0.1:7860 root@95.3.33.46
```

Откройте **http://127.0.0.1:17860**. В разделе подключения оставьте адрес пустым и введите действующий API-ключ команды. Затем загрузите `.mov`.

Ключ выдаётся отдельно: в репозитории и JS-сборке его нет. SSH-туннель — доступ команды, **не публичный адрес для жюри**. Публичный HTTPS-адрес и проверка внешнего доступа описаны в [чек-листе сдачи](docs/SUBMISSION.md).

## Разработка интерфейса на Mac с серверной моделью

1. Поднимите SSH-туннель из предыдущего раздела.
2. В отдельном терминале:

```bash
cd backend
python3 -m venv .venv-web
source .venv-web/bin/activate
pip install -r requirements-web.txt
FORTE_API_UPSTREAM=http://127.0.0.1:17860 \
  python -m uvicorn service.gateway:app --host 127.0.0.1 --port 8080
```

3. В другом терминале:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес Vite, оставьте API URL пустым, введите ключ. Модели остаются на GPU-сервере; на Mac повторно скачивать их не нужно.

## Полный запуск на GPU

Нужны Linux, Python 3.12, NVIDIA GPU с 24 GB VRAM, FFmpeg/FFprobe и локальные веса. Пошаговая инструкция: [backend/README.md](backend/README.md). Модели и точные версии: [DEPLOYED_MODELS.md](backend/DEPLOYED_MODELS.md).

```text
Браузер → gateway / React → FastAPI → очередь → один GPU worker
                                      ↓
                             JSON + JPEG + нормативные ссылки
```

Во время анализа нет обращений к внешним AI API. Один GPU worker исключает параллельную загрузку нескольких экземпляров моделей. Исходные API-видео удаляются после обработки; результаты и кадры остаются в закрытом каталоге заданий.

## API для жюри

| Запрос | Назначение |
|---|---|
| `POST /api/v1/analyze` | multipart `file`, непустой MOV до 200 MiB → `job_id` |
| `GET /api/v1/jobs/{job_id}` | `processing` / `done` / `failed` |
| `GET /api/v1/health` | готовность worker, очередь; без ключа |
| `GET /docs` | интерактивная схема API |

Анализ и результаты защищены `X-API-Key`. Один адрес обслуживает UI и API, поэтому отдельный CORS не нужен. [Примеры запросов и JSON](docs/API.md).

## Честно о качестве

Серверная версия ранее получила **15/21 положительных видео и 0/19 ложных срабатываний на отрицательных** по бинарному вердикту на знакомом наборе. Это не 15 безошибочно объяснённых событий и не независимая оценка на новых ракурсах. Кандидат 17/21 и экспериментальные LoRA в эту сборку не включены. В интерфейсе показываются реальные ответы сервера, без подстановки ответов по имени файла.

Некоторые сценарии пока не поддержаны, возможны неверные причины и пропуски. [Ограничения и происхождение компонентов](docs/PROVENANCE.md). Подключение фронтенда не улучшает качество модели; обучение продолжим отдельно после фиксации сдаваемой версии.

## Правила и официальные источники

Визуальное событие сопоставляется с локальным справочником нормативных актов РК. Ответ содержит название документа, пункт и официальный URL Әділет. Сохранены официальные тексты для проверки цитат. Наличие цитаты не подтверждает все условия нарушения: интерфейс отличает условное основание, связанную норму и отсутствие прямого основания. Qwen **не выбирает статью автоматически в рабочей версии**: эксперимент такого выбора не прошёл проверку и не подключён.

## Поддерживаемые сценарии и ограничения

| Категория | Рабочий поиск |
|---|---|
| A — предметы/ценности оставлены без присмотра | Включён; содержимое сумки или папки визуально не гарантируется |
| B — открытый сейф | Включён; применимость нормы условная |
| C — наличные на столе при следующем посетителе | Включён |
| E — дополнительный человек / человек за кассиром | Включён; полномочия человека неизвестны |
| F — передача сумки и уход передающего | Включён; отсутствие проверки не всегда доказуемо |
| G — личные предметы / питьё | Включён |
| H — открытая дверь при работе | Включён |
| L — признаки незаблокированного рабочего места | Включён; прямое нормативное основание не установлено |
| D — отсутствие проверки подлинности; I — отсутствие идентификации; J — пересчёт без клиента | В рабочий поиск не включены |

ТЗ не задаёт обязательный список из 21 типа: 21 — число положительных видео нашей оценки, 19 — отрицательных. Пропуски, неверный тип/момент и новый ракурс остаются рисками. Результат `no_violation` означает отсутствие найденных признаков, а не доказательство отсутствия всех нарушений.

Общий срок до пяти минут под произвольной нагрузкой не гарантирован: очередь последовательная. Во время сдачи нельзя занимать тот же GPU обучением. Новые веса подключать только после сравнения с зафиксированной версией. Тестовые записи жюри не использовать для обучения и не публиковать.

### Локальный пример видео

Локальный тест видео: в «Обзоре» нажмите «Открыть тестовое видео». Открывается Х-26 из архива, событие разметки — 00:09. Плеер: метки событий, скорость 0,25–2×, перемотка ±1 с, повтор ±3 с вокруг события, сохранение JPEG из текущего кадра. Пример переключает интерфейс в демо; модель не запускается. Файл `frontend/public/demo/x-26.mov` локальный и исключён из Git.
